# 05. UX

## Overview

UX is what makes a product feel intuitive and premium. It is not only about visual attractiveness; it is about clarity, feedback, and flow.

## Core UX ideas

- visible hierarchy
- immediate feedback
- smooth transitions
- loading and completion states
- accessible contrast
- consistent motion language

## Micro-interactions to include

- button press feedback
- list item reveal
- bottom sheet slide-up
- login form success state
- onboarding progression
- success checkmark after action

## Timing guidance

- 150–250ms: quick click feedback
- 250–500ms: motion transitions
- 500–700ms: onboarding or major screen transitions
